## What it is

A tiny viewer for relationship data — chats, parts, notes, anything with nodes and edges. Feed it one JSON object and it renders three reading views of the same data: an interactive graph (drag, timeline playback, search, new-arrival highlight), cards for scanning, and a collapsible tree for reading from a folded state. No build step, no CDN, no tracking. It runs from a single HTML file, even offline or from file://.

## Data shape

{ nodes: [{ id, label, cluster, day, role }], edges: [{ a, b, t, day }], events: [{ day, text }] } That is the whole contract. Clusters group nodes; day drives the timeline and the new-arrival highlight.
